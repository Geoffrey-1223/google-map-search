# Google Place Search App

A React-based frontend application that allows users to search for places using a mock Google Places dataset and view selected place details in a map-style interface.

This project demonstrates modern frontend architecture using React, Redux Toolkit, and Redux-Saga with a scalable and production-ready structure.

## ⚠️ Important Notes

- Google Places API (Maps JavaScript API) was referenced from official documentation but not implemented in this project.
- This is due to Google Cloud billing requirements, which require enabling a billing account and credit card.
- To keep the assessment setup simple and risk-free, a mock dataset is used instead of live API calls.
- The application architecture is designed to allow easy replacement of mock data with real Google Places API integration in the future.

---

## 🚀 Features

- Google Places Autocomplete (mock implementation)
- Search places from dataset
- Dynamic dropdown suggestions
- View selected place details (address, description, coordinates)
- Redux Toolkit for state management
- Redux-Saga middleware integration
- Search reset handling
- Responsive UI with Bootstrap
- Scalable component-based architecture
